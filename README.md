# 📊 Sales Data Analysis

A beginner-friendly data analysis project using Python and Pandas.

## 🎯 Project Objective

Analyze sales data to identify:

- Total revenue
- Total units sold
- Average transaction value
- Best-selling product
- Regional sales performance
- Data quality issues

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook
- CSV
- GitHub
